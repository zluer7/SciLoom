# SciLoom 科研舱

SciLoom 是面向科研人员的 AI 辅助桌面科研管理工作台，以本地科研工作流为中心。

当前为 **V1 测试版**，提供 Windows x64 与 macOS Apple Silicon 测试安装包。

## 主要能力

- 组织课题、路线、任务、实验、文献、复盘和成果，串联日常科研工作。
- 利用相关科研背景辅助 AI 交流与内容整理。
- 软件负责流程，AI 辅助内容，用户决定是否采纳；AI 建议或草稿需经预览和显式确认后写入。
