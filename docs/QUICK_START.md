# SciLoom 快速开始

SciLoom 是面向科研人员和研究生的本地优先科研管理与 AI 辅助科研工作流工具。你可以用它整理课题、路线、任务、实验、文献、复盘和成果，并让 AI 协助分析与生成操作建议。

SciLoom 当前为测试版本，仍可能存在未发现的问题。我们会持续根据真实使用反馈修复并改进，并尽快推出更稳定的版本。

## 1. 第一次启动：准备工作区

第一次启动时，SciLoom 会显示“准备 SciLoom 工作区”。点击“选择目录”，选择一个你有权使用、便于长期保存的本地目录。

工作区是 SciLoom 用于保存和组织本地科研数据的目录。选择完成后，SciLoom 会准备“西湖醋鱼”示例课题。建议先浏览示例，再创建自己的真实课题。

## 2. 浏览“西湖醋鱼”示例课题

示例课题的完整名称是“西湖醋鱼关键工艺参数与品质稳定性优化研究”。它用于帮助你快速理解课题、路线、任务、实验、文献、复盘和成果之间的关系，不是你的真实科研项目。

推荐顺序：先浏览示例课题及各页面之间的关联，再开始创建和整理自己的课题。

## 3. 配置 AI 功能

SciLoom 的 AI 功能需要你自行配置当前支持的 AI 服务商和 API Key。没有配置 API Key 时，科研管理、浏览和基础记录功能仍可使用，但“AI 对话”和“生成并解析建议草稿”等需要调用模型的功能无法正常使用。

配置步骤：

1. 打开左侧的“设置”。
2. 在“AI 功能”中，从“服务提供方”和“模型”列表选择你要使用的选项。
3. 在“API Key”中输入对应服务的密钥。
4. 点击“保存”。

请只使用界面当前列出的服务提供方和模型，并使用你自行申请且有权使用的 API Key。

## 4. 本地数据与 AI 使用边界

- API Key 由你自行配置；SciLoom 安装包不内置开发测试密钥。
- 科研数据以本地保存和管理为主。
- 只有在你发起 AI 操作并确认发送后，SciLoom 才会按当前操作使用发送前可预览、由你选择或授权的必要上下文。
- AI 输出是建议或草稿，不会自动成为正式业务记录；需要写入时，仍须由你预览并明确确认。

## 5. 遇到问题时反馈

如果你在安装、AI 配置或日常使用中遇到问题，或有功能建议，欢迎通过 SciLoom 公众号「争流儿的科研舱」反馈。

反馈时建议附上问题发生的步骤、所在页面、提示信息和截图。请勿发送 API Key、密码、完整敏感科研数据或凭据文件。
